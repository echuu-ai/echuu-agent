# Few-shot 内容隔离与本地复测（2026-09-11）

目标：让示例只影响表达节奏，不成为主播的人物经历或剧情来源。轨道 research，API/WS 为本地 127.0.0.1:8000；未部署平台后端。

## 修正

- `ExampleSampler.format_as_fewshot` 不再把切片标题、备注、结构描述、口癖原文和 transcript 送进编剧提示；只输出由段落长度统计映射的固定节奏类别。原素材保留供离线分析，采样 ID 仍可追踪。
- 默认 legacy/shareable 生成器明确本次设定优先；审查与修复不能把用户明确的事件改成未发生。旧 casual 提示中的可模仿动作例句改成类别说明。
- 当前用户背景、历史记忆、联网主题简报标注来源与优先级；检索结果不是主播经历，不能推翻虚构情境。
- 开场收到本次用户背景；收尾收到本次背景和通过 WS 发出的台词，包括实际弹幕/礼物改写。避免仅凭话题另起故事。
- 启动 skill 增加进程启动时间与源码新鲜度检查。
